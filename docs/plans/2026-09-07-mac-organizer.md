# mac-organizer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a fully automatic macOS file-tidying system (Python router + launchd agents) plus a ready-to-use Obsidian vault template.

**Architecture:** A single-file router engine (`route.py`) reads ordered rules from `rules.toml` and moves/renames files in drop-zone folders to permanent homes. `plist.py` renders launchd agent definitions; `setup.py` creates folders, detects the screenshot location, generates `rules.toml`, installs five launchd agents, and copies the Obsidian vault template into `~/Notes`. Thin `install.sh` / `uninstall.sh` wrappers load and unload the agents.

**Tech Stack:** Python 3.11+ standard library only (`tomllib`, `plistlib`, `shutil`, `argparse`, `fnmatch`). pytest for tests. Bash for the two wrapper scripts. macOS `launchd` for scheduling.

**Spec:** `docs/specs/2026-09-07-mac-organizer-design.md`

## Global Constraints

- Python **>= 3.11** (needs stdlib `tomllib`). Target interpreter is Homebrew `python3` (`sys.executable` at setup time is baked into the generated plists).
- **Standard library only** for all runtime code. The only dev dependency is `pytest`.
- Every filesystem operation is confined to `$HOME`; `route.py` refuses any destination that resolves outside `Path.home()`.
- **Never overwrite** an existing file: on collision insert ` -2`, ` -3`, … before the extension.
- **Never delete** a file. The only action on a file is a move.
- Every real move appends exactly one line to the action log, format: `<ISO8601-UTC>  <ACTION>  <src> -> <dst>` (two spaces between fields).
- launchd label prefix is `com.mac-organizer.` (e.g. `com.mac-organizer.sweep`).
- Every entrypoint is **idempotent**: a second run with no new files produces no changes and no new log lines.
- Safety skips enforced always (not rule-configurable): filenames starting with `.`, suffixes `.crdownload` `.part` `.download` `.tmp`, and any file whose mtime is under 60 seconds old.

**Deviations from spec (intentional):** The spec described `launchd/*.plist.tmpl` text templates and a `--once` CLI flag. This plan builds plists programmatically with `plistlib` (testable, no string templating) and omits `--once` (there is no daemon mode). Both changes reduce surface area without changing behavior.

```python
"""Automatic file router for macOS drop-zone folders."""

from __future__ import annotations

import tomllib
from dataclasses import dataclass
from pathlib import Path


@dataclass(frozen=True)
class Rule:
    source: Path
    action: str
    dest: str = ""
    ext: frozenset[str] = frozenset()
    glob: str | None = None
    min_age_seconds: int = 0


def _norm_ext(values) -> frozenset[str]:
    return frozenset(str(v).lower().lstrip(".") for v in values)


def load_rules(path: Path) -> list[Rule]:
    with open(path, "rb") as fh:
        data = tomllib.load(fh)
    rules: list[Rule] = []
    for entry in data.get("rule", []):
        rules.append(
            Rule(
                source=Path(entry["source"]).expanduser(),
                action=entry["action"],
                dest=entry.get("dest", ""),
                ext=_norm_ext(entry.get("ext", [])),
                glob=entry.get("glob"),
                min_age_seconds=int(entry.get("min_age_seconds", 0)),
            )
        )
    return rules


def sources(rules: list[Rule]) -> list[Path]:
    return sorted({r.source for r in rules})
```

MIN_AGE_SECONDS = 60
SKIP_SUFFIXES = frozenset({".crdownload", ".part", ".download", ".tmp"})


def _age_seconds(path: Path, now: float) -> float:
    return now - path.stat().st_mtime


def should_skip(path: Path, now: float) -> bool:
    if path.name.startswith("."):
        return True
    if path.suffix.lower() in SKIP_SUFFIXES:
        return True
    return _age_seconds(path, now) < MIN_AGE_SECONDS


def rule_matches(rule: Rule, path: Path, now: float) -> bool:
    if rule.ext and path.suffix.lower().lstrip(".") not in rule.ext:
        return False
    if rule.glob and not fnmatch.fnmatch(path.name, rule.glob):
        return False
    if rule.min_age_seconds and _age_seconds(path, now) < rule.min_age_seconds:
        return False
    return True


def match_rule(path: Path, rules: list[Rule], now: float) -> Rule | None:
    for rule in rules:
        if rule_matches(rule, path, now):
            return None if rule.action == "skip" else rule
    return None
```

def resolve_dest(dest: str, mtime: float) -> Path:
    expanded = datetime.fromtimestamp(mtime).strftime(dest)
    return Path(expanded).expanduser()


def within_home(path: Path) -> bool:
    home = Path.home().resolve()
    resolved = path.resolve()
    return resolved == home or home in resolved.parents


def timestamp_name(mtime: float, suffix: str) -> str:
    return datetime.fromtimestamp(mtime).strftime("%Y-%m-%d_%H-%M-%S") + suffix


def dedupe(path: Path) -> Path:
    if not path.exists():
        return path
    counter = 2
    while True:
        candidate = path.with_name(f"{path.stem} -{counter}{path.suffix}")
        if not candidate.exists():
            return candidate
        counter += 1
```

```python
@dataclass(frozen=True)
class Action:
    src: Path
    dst: Path


def plan_action(path: Path, rule: Rule, now: float) -> Action | None:
    mtime = path.stat().st_mtime
    dest_dir = resolve_dest(rule.dest, mtime)
    if not within_home(dest_dir):
        raise ValueError(f"destination outside home: {dest_dir}")
    if rule.action == "move_and_timestamp":
        target = dest_dir / timestamp_name(mtime, path.suffix)
    else:
        target = dest_dir / path.name
    if target == path:
        return None
    return Action(src=path, dst=dedupe(target))


def _log(log_path: Path, verb: str, src: Path, dst: Path) -> None:
    log_path.parent.mkdir(parents=True, exist_ok=True)
    stamp = datetime.now(timezone.utc).isoformat()
    with open(log_path, "a") as fh:
        fh.write(f"{stamp}  {verb}  {src} -> {dst}\n")


def apply_action(action: Action, dry_run: bool, log_path: Path) -> None:
    if dry_run:

DEFAULT_LOG = Path("~/.local/state/mac-organizer/actions.log").expanduser()


def process_dir(
    directory: Path,
    rules: list[Rule],
    now: float,
    dry_run: bool,
    log_path: Path,
) -> list[Action]:
    dir_rules = [r for r in rules if r.source.resolve() == directory.resolve()]
    done: list[Action] = []
    for child in sorted(directory.iterdir()):
        if not child.is_file():
            continue
        if should_skip(child, now):
            continue
        rule = match_rule(child, dir_rules, now)
        if rule is None:
            continue
        try:
            action = plan_action(child, rule, now)
        except ValueError as exc:
            _log(log_path, "ERROR", child, Path(str(exc)))
            continue
        if action is None:
            continue
        apply_action(action, dry_run, log_path)
        done.append(action)
    return done


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(description="Route files in drop-zone folders.")
    parser.add_argument("--dry-run", action="store_true")
    parser.add_argument(
        "--rules",
        type=Path,
        default=Path(__file__).resolve().parent / "rules.toml",
    )
    parser.add_argument("--log", type=Path, default=DEFAULT_LOG)
    parser.add_argument("paths", nargs="*", type=Path)
    args = parser.parse_args(argv)

    rules = load_rules(args.rules)
    targets = args.paths or sources(rules)
    now = time.time()
    for target in targets:
        directory = target.expanduser()
        if directory.is_dir():
            process_dir(directory, rules, now, args.dry_run, args.log)
    return 0

"""Render launchd agent property lists for mac-organizer."""

from __future__ import annotations

import plistlib
from pathlib import Path


def _base(label: str, program_args: list[str], state_dir: Path) -> dict:
    return {
        "Label": label,
        "ProgramArguments": program_args,
        "StandardOutPath": str(Path(state_dir) / f"{label}.out.log"),
        "StandardErrorPath": str(Path(state_dir) / f"{label}.err.log"),
        "RunAtLoad": False,
    }


def render_watch(
    label: str, python: str, route_py: Path, watch_dir: Path, state_dir: Path
) -> bytes:
    data = _base(label, [python, str(route_py), str(watch_dir)], state_dir)
    data["WatchPaths"] = [str(watch_dir)]
    return plistlib.dumps(data)


def render_sweep(
    label: str,
    python: str,
    route_py: Path,
    dirs: list[Path],
    interval: int,
    state_dir: Path,
) -> bytes:
    data = _base(
        label, [python, str(route_py), *(str(d) for d in dirs)], state_dir
    )
    data["StartInterval"] = interval
    data["RunAtLoad"] = True
    return plistlib.dumps(data)

from pathlib import Path

def launch_agents_dir() -> Path:

def detect_screenshot_dir(runner=subprocess.run) -> Path:
    try:
        result = runner(
            ["defaults", "read", "com.apple.screencapture", "location"],
            capture_output=True,
            text=True,
            check=True,
        )
        value = (result.stdout or "").strip()
        if value:

    except (subprocess.CalledProcessError, FileNotFoundError, OSError):

    if out_path.exists():
        return False
    text = default_path.read_text().replace("@@SCREENSHOT_DIR@@", str(screenshot_dir))
    out_path.write_text(text)
    return True

```markdown
# mac-organizer

A fully automatic file-tidying system for macOS, plus a ready-to-use Obsidian
vault. Files that land in your drop zones are moved to permanent homes by a
small Python script triggered by `launchd`. No GUI, no third-party
dependencies.

## Requirements

- macOS
- Python 3.11 or newer on your `PATH` (`brew install python`)

## Install

```bash
git clone <this repo> ~/.mac-organizer
cd ~/.mac-organizer
./install.sh
```

`install.sh`:

1. Runs `setup.py`, which creates `~/Inbox`, `~/Media/Images`,
   `~/Media/Screenshots`, `~/Documents/Inbox`, `~/Downloads/Installers`, and
   the state directory; detects your screenshot location; generates
   `rules.toml`; installs five `launchd` agents; and copies the Obsidian
   vault template to `~/Notes` (never overwriting existing files).
2. Loads the agents with `launchctl`.
3. Prints a dry-run preview of what the router would do right now.

Then open Obsidian and "Open folder as vault" → `~/Notes`.

## What gets moved where

Routing is defined in `rules.toml` (generated from `rules.default.toml`).
Defaults:

| From | What | To |
| --- | --- | --- |
| Screenshots folder | `Screenshot *`, `Screen Recording *` | `~/Media/Screenshots/YYYY-MM/`, renamed `YYYY-MM-DD_HH-MM-SS` |
| `~/Desktop` | everything (after 60s) | `~/Inbox` |
| `~/Downloads` | images | `~/Media/Images` |
| `~/Downloads` | pdf / office docs | `~/Documents/Inbox` |
| `~/Downloads` | `.md` / `.txt` | `~/Notes/00-Inbox` |
| `~/Downloads` | dmg / pkg / archives | `~/Downloads/Installers` |
| `~/Inbox` | same rules as Downloads | permanent homes |

Anything not matched is left alone. Files are only ever moved, never deleted
or overwritten (name collisions get a ` -2` suffix). Files newer than 60
seconds and partial downloads (`.crdownload`, `.part`, `.download`, `.tmp`)
are skipped.

## Changing the rules

Edit `~/.mac-organizer/rules.toml`. Each `[[rule]]` has a `source` folder, an
`action` (`move`, `move_and_timestamp`, or `skip`), a `dest`, and optional
`ext`, `glob`, and `min_age_seconds` filters. Rules are evaluated top to
bottom per source folder; the first match wins. No restart needed — the next
run picks up the changes.

To preview without moving anything:

```bash
python3 ~/.mac-organizer/route.py --dry-run
```

## Logs

Every move is logged to `~/.local/state/mac-organizer/actions.log`. Agent
stdout/stderr go to `~/.local/state/mac-organizer/com.mac-organizer.*.log`.

## After changing your screenshot location or upgrading Python

Re-run `./install.sh`. It regenerates the agents (the Python path is baked
into them) and, if `rules.toml` does not yet exist, regenerates it with the
new screenshot path. To force `rules.toml` regeneration, delete it first
(your edits will be lost).

## Uninstall

```bash
cd ~/.mac-organizer
./uninstall.sh
```

Removes the `launchd` agents only. Your files, `rules.toml`, `~/Notes`, and
logs are left in place.

## Optional Obsidian plugins

The vault ships with core plugins configured (Templates, Daily Notes, Tags).
For faster capture, consider the community plugins **Templater** and
**QuickAdd** — install them from within Obsidian.
